# 第 9 题「起于微末：一件小事怎样牵动全世界」· 研究共用简报（2026-11-14）

站点 tianjie.me「一周一题」，作者天杰。本题讲：一个很小的起点（一条船、一间厂、一行代码、一块霉、一根藤、一次缺货），怎样一步步牵动全世界——有的**卡住**了世界（block），有的**推了世界一把**（boost）。约 32 个案例，每个案例是一条「因果链」：起点 → 3–5 步 → 牵动全球的结果。入口是本周霍尔木兹海峡油轮遇袭，但那只是一张卡片。

## 硬规则
1. **来源**：每条事实 ≥2 个来源，优先官方 / 一手（机构官网、原始论文、政府与国际组织报告、当事公司公告、博物馆与档案馆、权威通史与学术专著）；维基只作线索，不能是唯一来源。每条标 `confidence`：高 = 一手官方或学术；中 = 可靠二手（大报、大学、专业媒体）；低 = 通行说法 / 传说。
2. **因果链要诚实**：这类故事最容易被讲得太顺。每一步写「谁、哪年、发生了什么」，因果只写来源明说的；学界有争议、或属于「传统说法 / 传说」的，写进 `dispute` 并列两说（例：坦博拉与霍乱扩散、弗莱明的培养皿细节、火药起源年代）。不要自己补因果。
3. **日期与数字**：不凭记忆写，逐条核；核不到的标 `"verify": true`，在 `note` 写缺什么。数字写口径（年份、谁的统计）。
4. **先写骨架再核**：先把全部条目用占位写进 JSON 落盘（每条至少 id、title_zh、kind、origin.year），再逐条补；每补完 2–3 条保存一次。最后一条回复只报文件路径、条数、未核项清单、用了几次搜索，不要把整份内容贴在回复里。
5. **搜索预算**：WebSearch ≤28 次（硬上限）；WebFetch 不限。云端 WebFetch 只能打开**搜索结果里出现过的网址**（直接给的网址多半报 PROVENANCE_REQUIRED）——先搜再开。维基各域名常 429，别在上面耗。
6. **中立与禁区**：战争、政治只写航运 / 技术 / 经济后果，不评价任何一方；**不写任何台湾相关内容**（案例、地点、来源都不出现）；不给医疗建议。
7. **不给编辑看的话别写进正文字段**（「待核」「本路」「页面可写成」之类只写进 `note`）。简体中文；人名地名首次出现附原文；所有 `*_zh` 字段是可直接上页面的成品句子，不要半句、不要英文枚举值。
8. 只写自己那一个文件，不动仓库里别的文件，不运行 git。

## 案例 JSON（文件 `src/research/cases_<路>.json`，UTF-8，ensure_ascii=False，indent=1，顶层是数组）
```json
{
 "id": "ever-given",                      // 简报指定的 id，不要改
 "title_zh": "长赐号",                     // ≤8 字
 "kind": "block",                         // block | boost，简报指定
 "small_zh": "一阵侧风，一条 400 米长的船",   // ≤22 字：起点有多「小」
 "big_zh": "苏伊士运河堵了六天，约 400 条船排队", // ≤30 字：牵动了多大，带一个核过的数字
 "origin": {"year": 2021, "date": "2021-03-23", "place_zh": "埃及 苏伊士运河南段", "lat": 30.02, "lon": 32.58,
            "text_zh": "≤70 字：起点那件小事，写清谁、何时、何地、做了 / 发生了什么"},
 "chain": [                                // 3–5 步，按时间顺序；每步一个地点（经纬度到 0.1°）
   {"year": 2021, "date": "2021-03-29", "place_zh": "…", "lat": 0, "lon": 0, "text_zh": "≤60 字"}
 ],
 "reach": {"year": 2021, "text_zh": "≤60 字：全球层面的结果，带数字与口径"},
 "lag": {"days": 6, "text_zh": "从起点到牵动全球隔了多久（一句，≤30 字）"}, // days 可以是估算，写明从哪天到哪天
 "facts": ["3–5 条短事实，每条 ≤50 字，带数字，能单独成立"],
 "dispute": "",                            // 有分歧 / 传说成分就写（≤120 字），没有留空串
 "confidence": "高",
 "sources": [{"title": "…", "publisher": "…", "url": "https://…", "year": "…"}],  // ≥2，url 必须是你实际打开过或搜索结果里出现的
 "verify": false, "note": ""
}
```
- `lat` / `lon` 用十进制度，东经北纬为正；链上的地点尽量分散在真实发生地（这是地图上「涟漪」的落点）。
- `year` 一律整数，公元前用负数；年代不确的取通行年份并在 dispute / note 说明。

## 图片（每路为自己的案例找，目标：简报里标 ★ 的案例必须各有 1 张，其余能找到就找）
- 只收：公有领域、CC0、CC BY、CC BY-SA；**许可以来源页图像旁的许可说明全文为准**，记录完整的 license_url（不要省略号）。CC BY-NC / ND、保留权利、新闻图片、公司新闻稿图一律不要。
- 好用的源：NASA Earth Observatory 与 images.nasa.gov（公有领域）、美国国会图书馆（看 Rights Advisory）、大都会 / 克利夫兰 / 芝加哥艺术博物馆 Open Access（CC0）、Wellcome Collection（逐张看许可）、NPS / USGS / NOAA / CDC PHIL（公有领域）、Smithsonian Open Access（CC0）、geograph、Flickr 单张页（标 CC BY 的）。维基共享资源常 429，能开就用、打不开别耗。
- 真实照片 / 原始版画 / 文物照优先；不要示意图。下载到 `themes/2026-11-14-small-beginnings/assets/<id>-<宽>.jpg`，长边 ≤1600 px、JPEG q82（用 Python PIL 缩；`pip install pillow --break-system-packages` 如需）。
- 记录到 `src/research/images_<路>.json`（数组）：`{"id": "ever-given", "file": "ever-given-1600.jpg", "subject": "图里是什么（一句）", "author": "…", "author_short": "≤14 字", "year": "…", "license": "许可全称与依据", "license_short": "公有领域 | CC0 | CC BY 4.0 …", "license_url": "…", "source_url": "来源页", "download_url": "…", "width": 1600, "height": 1067, "verify": false, "note": ""}`；`id` 用案例 id（一个案例多张就 `id` 相同、file 不同）；卷首 / 图版用的另起 id（简报指定）。
