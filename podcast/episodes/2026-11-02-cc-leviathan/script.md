# 合读 · CC 读书会 第 1 周 · 霍布斯《利维坦》：没有刀剑的信约，只是空话

## 开场

一五八八年春天，西班牙无敌舰队要来打英格兰的风声传遍全国。风声传到一个小镇，一位牧师的妻子被吓得早产，生下一个男孩。这个男孩后来在自传里写：我母亲那年生了一对双胞胎，一个是我，一个是恐惧。被无敌舰队的风声吓出来的早产儿、自称跟恐惧是双胞胎、给流亡的英国王储当过数学老师、活到九十一岁还在跟人吵几何题的英格兰硬核老头——托马斯·霍布斯。这位老哥一辈子最绕不开的就一件事：人怕死，那该怎么办。

欢迎回到合读。这一期开始，我们开一条新线：跟着哥伦比亚大学的 Contemporary Civilization 书单，一周读一本，一共十二周。第一周，读霍布斯的《利维坦》。

为什么第一周不是书单上排第一的柏拉图，而是霍布斯？因为这本书直接回答了一个今天很多人正在面对的问题。你给家里一台机器上的 agent 开了权限，它能持续替你办事。它什么时候必须停下来问你？什么时候你可以收回权限？要是它哪天合情合理地干了一件你事后不同意的事，锅归谁？我问过几个人，答得最好的版本大致是：不可逆、而且会作用到真实的人和组织的操作，它必须先确认；责任在我；规则是人定的，人定的就会有没顾到的边界，而定这个规则、准许机器去干这件事本身，就是人的责任。

这段话，霍布斯在一六五一年写过一个几乎一模一样的版本。他把你叫"作者"，把机器叫"演员"，把它替你办事所凭的那份权利叫"授权"。所以这一周，不能说是从零学一本三百多年前的政治哲学吧，至少也可以说是，去看一个很多人已经想明白一半的问题，另一半长什么样。

怎么读：这期节目不代替读书，它是读前的地图、读后的考核。读四章：第十三章，人类的自然状况；第十四章，第一、第二自然律与契约；第十六章，人格、作者与被代表之物；第十七章，国家的成因、生成与定义。再加第十五章里讲"愚人"的那一段，两页。顺序就按十三、十四、十六、十七，第十六章读两遍。

每一章：先听这一段，拿到地图；再读原书；读完回节目页做那一组题。每组第一题永远是同一个：霍布斯最强的反对者会怎么说。这是大多数人读书时最不习惯干的事，这一周就把它练成习惯。

周日前一页纸，三段：一段写反方，一个不需要主权者的理由；一段把你给 agent 的授权改写成一份信约；最后一句话，读完第十六章，你原来关于"责任在谁"的答案哪里要改。

中译本常见的是商务印书馆的版本；英文原版一六五一年出版，早就是公有领域，古腾堡计划有全文。节目里引的原文都是我自己译的。好，进第十三章。

## 第一部分 · 第十三章：平等为什么会打起来

先请你想象一个场景，不是三百年前的，是你自己的。

假设你有三个 agent，各自跑在不同的机器上，各自理性，各自有目标。没有调度器，没有主权者，没有任何一个高于它们的东西。它们共享一个资源池：算力、API 配额、写同一个数据库的权限。问：它们会自然地合作吗？

大多数人的直觉是会。都是理性的，合作对大家都好，为什么不合作？

霍布斯的回答，从一个特别反直觉的前提开始：平等。他说，人在身体和心智上大致平等。注意他说的平等，不是道德上的人人平等，是能力上的：最弱的人，也有足够的力气弄死最强的人，靠阴谋，或者靠拉人入伙。至于脑子，他说得更损：每个人都觉得自己比大多数人聪明，这恰恰证明了大家差不多，因为没有什么比"每个人都对自己分到的那份满意"更能说明分配是平均的。

平等为什么是问题？他的推理分三步。第一步，能力平等，带来希望平等：两个人想要同一样东西，而这东西没法两个人都有，他们就成了敌人。第二步，敌意带来猜疑：你种了地、盖了房，别人可能联合起来把你赶走，不光拿走你的收成，连命一起拿走，于是没人能安心。第三步，猜疑带来先下手为强：既然没法确定别人不来打我，最合理的办法就是在别人动手之前先把他们控制住，直到看不见任何能威胁我的力量为止。而且他说，这不过是自保所要求的，一般来说是被允许的。

注意这个结构，每一步都是理性的。霍布斯也承认，有少数人就是以征服为乐，把地盘扩到安全所需之外；但他的要点是，哪怕只有少数这样的人，其余安分的人为了活下去，也得先动手。这就是你那三个 agent 不会自然合作的原因：它们不需要有恶意，只需要各自理性，再加上没有任何东西能保证对方不先动手。

然后他总结出人性里打架的三个根源：竞争、猜疑、荣誉。竞争为了得利，猜疑为了安全，荣誉为了名声。前两个你的 agent 都有：抢资源，抢着先写。第三个是人才有的：为了一句话、一个笑、一个不同的意见就能打起来。记住这个"荣誉"，第十七章讲人为什么不像蜜蜂的时候，它还会回来。

接下来是全书最有名的一段。他说，人们生活在没有一个共同权力让所有人敬畏的状态里，就处在战争状态，每个人对每个人的战争。然后他解释什么叫战争，这个解释值得停一下：战争不只是打仗这个动作，而是一段时间，在这段时间里，用武力解决问题的意愿是众所周知的。就像坏天气不是一两阵雨，而是连着好多天都倾向于下雨。只要没有相反的保证，这种已知的倾向就是战争，其余的时间才叫和平。

所以他说的战争状态，不是说大家每天在打，是说大家每天都知道随时可能打，所以谁也不敢投入长期的事。接着就是那句话，我自己译：在这种状态里，没有勤勉的余地，因为成果没有保障；没有农耕；没有航海，也用不上海运来的货物；没有舒适的建筑；没有搬动重物的器械；没有对地球面貌的知识；没有对时间的记录；没有技艺；没有文字；没有社会；最糟的是持续的恐惧和暴死的危险；人的生活，孤独、贫穷、肮脏、野蛮、短暂。

做工程的人对这一段应该特别有体感。他列的那一串，农耕、建筑、航海、记录时间，全是需要长期投入、晚期才回本的活动。战争状态首先弄死的不是人，是所有需要相信未来的活动。一个没有任何协调的多 agent 系统，死法一模一样：不是它们互相攻击，是它们谁也不敢接一个需要别人配合才能干完的长任务。不能说是兵荒马乱吧，至少也可以说是全员摸鱼。

然后霍布斯预判了两个反驳。第一个：人性真会这样吗？他不跟你讲道理，让你看自己的行为。你出门要带武器、要结伴，睡觉要锁门，在自己家里还要锁箱子，而这是在你明知有法律、有武装的公职人员替你报仇的情况下。你锁门的时候，对你的同胞是什么看法？你锁箱子的时候，对你的孩子和仆人是什么看法？他说，你用行动控诉人类，和我用文字控诉人类，是一回事。但他马上补一句：我们俩控诉的都不是人性，欲望和激情本身不是罪，在有法律禁止之前，由它们发出的行为也不是。这一招叫"用你自己的行为反驳你"，写一页纸的时候，对自己也可以用一次。

第二个反驳：真有这么一个时代吗？他先承认，从来没有全世界都这样过。然后给了三个例子。一是美洲，他说那里的人到现在还这样活着，这是十七世纪欧洲人的说法，带着那个时代的偏见，第九周读美洲征服单元的时候，你会从另一边看这件事。二是内战，原本生活在和平政府底下的人，打起内战来会退化成什么样子。三是国与国之间：国王们永远处在角斗士的姿态，武器指着对方，眼睛盯着对方，边境上的堡垒、驻军、大炮，还有间谍，这就是战争状态；只不过国王们靠这种姿态维持了臣民的生产，所以不会出现个人之间那种悲惨。

这一章倒数第二段，是整本书的枢纽，也是最容易被跳过的。他说，在这种每个人对每个人的战争里，没有什么是不正义的。对错、正义、不正义，在那里没有位置。没有共同权力，就没有法律；没有法律，就没有不正义。武力和欺诈，是战争里的两大主德。正义不是身体的官能，也不是心灵的官能，不然一个独自活在世界上的人也会有正义或不正义，就像他有感官和激情一样；正义是人在社会里才有的性质。同样，那里也没有财产，没有你的我的，只有能拿到就是谁的，能守住多久就是多久。

你看他在干什么：他把对错从大自然里拿掉了。对错不是被发现的，是被建立的，在某个人被指定来制定法律之后才出现。CC 第一学期那半张书单，从柏拉图一路读下来，走的就是从"秩序是被发现的"到"秩序是被约定的"这条线，第十三章就是这一步真正迈出去的地方。

但他留了个出口。让人倾向于和平的，有激情，也有理性。激情是对死的恐惧，对舒服日子的欲望，以及靠勤勉得到它们的希望；理性则提出了和平的条款，这些条款，就叫自然律。这就是第十四、十五章。

听到这儿先停一下，去读第十三章，不长。读完做第一组题。

## 第二部分 · 第十四章：什么可以让渡，什么永远不能

第十四章一开头是两个定义，整本书后面的论证都盖在这两个定义的区别上，读慢一点。

第一个，自然权利。自然权利是每个人用自己的力量保存自己生命的自由，也就是做任何在他自己的判断和理性看来最有助于保命的事的自由。注意"在他自己的判断看来"，这个判断权，是他自己的。

第二个，自然律。自然律是理性找到的一条规则，禁止人做毁灭自己生命、或者夺走保命手段的事，也禁止人不去做他认为最能保命的事。

然后他说，写这个题目的人常把权利和法律混为一谈，但必须分开：权利在于做或不做的自由，法律是决定你做哪一个、并且约束你的东西。法律和权利的差别，就像义务和自由的差别，在同一件事上两者不能并存。

这个区分对你马上有用。你给 agent 写规则的时候，哪些是它的"自由"，哪些是它的"律"，写清楚了吗？自由是它可以自己判断的空间，律是它不许越过的线。霍布斯整个体系，就是从"每个人起初对一切都有自由"推到"为了活下去，理性要求你放弃大部分自由，换取约束"。

接下来的推理很紧。在自然状态里，每个人对一切都有权利，连别人的身体也在内，因为任何东西都可能帮他保命。而只要这种人人对一切的权利还在，任何人都没有安全。所以理性给出基本规则：每个人都应当寻求和平，只要有获得和平的希望；得不到的时候，可以寻求并使用战争的一切帮助和好处。前半句是第一自然律，寻求和平并遵循它；后半句是自然权利的总和，用一切办法保卫自己。

第二自然律从第一条推出来：当别人也愿意的时候，一个人应当愿意，在他认为和平与自保所必需的范围内，放下对一切的权利，满足于他允许别人对他拥有的那么多自由。他自己说，这就是福音书里那条规则，你要别人怎么待你，你就怎么待人。但注意那个条件："当别人也愿意的时候"。别人不放下，你单方面放下，就是把自己送上门当猎物，没有人有这个义务。这是一个对等条款，不是道德要求。

然后他讲什么叫放下一个权利。放下权利，不是给别人一个他原来没有的权利，因为本来人人对一切都有权利；放下只是你站开，不再妨碍他享用他原有的权利。放下有两种：单纯放弃，不在乎好处落到谁头上；或者转让，把好处指定给某个人。一旦放弃或转让了，你就有了义务，不去妨碍对方，不去推翻自己这个自愿的行为。妨碍了，就叫不正义，叫侵害。他还打了个比方：不正义之于世事，就像荒谬之于学者的辩论，一个人先自愿做了某件事，然后又去推翻它，就像在辩论里否定自己一开始主张过的东西。不正义，是一种自己打自己的脸。

现在是这一章最重要的一段，也是开场那个答案没碰到的东西：有些权利是放不下的。他的论证是，放下权利是自愿的行为，而自愿行为的目的总是对自己有好处。所以有些权利，无论用什么话、什么表示，都不能被理解为已经放弃或转让了。第一个，一个人不能放下抵抗那些用武力来夺他性命的人的权利，因为没有人能被理解为从中图到了什么好处。伤害、锁链、监禁也一样。放下任何权利的唯一目的是保全自己，一句让你不许自卫的话，不能被理解为你的本意，只能理解为你不懂这句话该怎么解释。本章后面他又单独说了一条：不自卫的信约，永远无效。

这一条你要记住，它是整本书里对主权者权力的内置限制，也是你那份 agent 信约里必须有的一条：有些东西你永远不委托出去，不是因为你不想，而是因为委托它们，和你委托的目的自相矛盾。

然后是契约和信约。双方相互转让权利，叫契约。契约里如果一方先履行、另一方以后再履行，或者双方都约定以后履行，中间靠信任，这种契约叫信约。信约的履行叫守信，自愿的不履行叫背信。信约的关键是时间差：有一方得先信任另一方。整本书后面说的都是信约，因为政治关系永远有时间差。

接着他问：在自然状态里，信约有效吗？他的回答是：如果双方都不立刻履行，而是互相信任，那么在自然状态里，只要有任何合理的怀疑，这份信约就无效；但如果有一个共同权力站在两人之上，有足够的权利和力量强制履行，它就有效。理由是，先履行的那个人，没有任何保证对方以后也会履行，因为言语的约束太弱，驯服不了人的野心、贪婪、愤怒，除非有对强制力量的恐惧。所以在自然状态里先履行的人，只是把自己交给了敌人。

这一段，就是第十七章那句"没有刀剑的信约只是空话"的全部论证，提前出现在这儿。做系统对接的人对这一段的体感应该是：一个没有执行机制的接口约定，只要对方出现任何合理的违约迹象，就立刻失效，不是道德上失效，是逻辑上失效，因为先照约定干的那一方扛了全部风险。霍布斯还特意补了一句：这个迹象得是立约之后才出现的，签的时候就知道的风险，不能拿来当不履行的借口。

这一章后面还有几条，挑三条跟你有关的。一，转让一个权利的人，也就转让了享用它的手段：卖地的人也卖了地上的草，卖磨坊的人不能把推磨的水流引走；把统治权交给主权者的人，也就给了他征税养兵、任命法官的权利。你给 agent 一个目标，也就给了它达成目标的手段，除非你明确收回某些手段。二，跟野兽不能立信约，因为它们不懂我们的语言，不能接受也不能转让权利。这一条可以多想一会儿：一个能理解语言、能接受条款的机器，在霍布斯的框架里算什么？他没有答案，这个问题是你的。三，出于恐惧订立的信约也有效：向敌人许诺付赎金换命，是有效的，得付。这一条很多人读了会不舒服，但它对霍布斯很关键：要是恐惧之下的承诺可以作废，那所有的政治服从都可以作废，因为所有政治服从，归根到底都出于对死的恐惧。毕竟这位老哥，跟恐惧是双胞胎。

读完第十四章，做第二组题。

## 第三部分 · 第十六章：作者、演员、授权

第十六章只有几页，但它是开场那个问题的答案出处，读两遍。

霍布斯先定义"人格"。人格是这样一个人，他的言语和行为，要么被看作他自己的，要么被看作代表另一个人、或者任何别的东西的。被看作自己的，叫自然人格；被看作代表别人的，叫虚拟的、或者人为的人格。

然后他讲这个词的来历，这段很有意思。"人格"这个词是拉丁文，对应的希腊文是"面孔"；拉丁文原来的意思是舞台上的伪装和外表，特别是遮住脸的那部分，面具。后来从舞台转到任何代表别人说话行事的人，法庭上的和剧场里的一样。所以人格和演员是一回事。扮演别人的人，叫承担他的人格，或者以他的名义行事。他列了一串词：代表、副手、代理人、受托人、代办、演员。你看，三百多年前的代理人清单，不能说是跟今天的 agent 一模一样吧，至少也可以说是一脉相承。

接下来是核心的三个词。人为人格当中，有一些人的言语和行为，是由他们所代表的人"拥有"的。这时候，这个人格就是演员，拥有他言行的那个人，叫作者。演员凭授权行事。他类比说：说到财物，所有权人叫主人；说到行为，就叫作者。占有的权利叫所有权，做某个行为的权利就叫授权。所以授权永远指做某个行为的权利；凭授权做，就是凭那个权利的主人的委托或许可来做。

好，把开场那个答案放进来对照。那个答案说，规则是我定的，准许它做，就是我的责任。霍布斯会说，说对了，而且他有一个更精确的词：你是作者，它是演员，它的行为归你所有。这是第一层。

第二层，是那个答案没说的，也是一页纸里要补的。他说，演员凭授权立下信约，就约束了作者，跟作者亲自立的没有两样，作者要承担同样的一切后果；而且约束的范围是在委托范围之内，不能更远。接着一句很关键：跟演员立约的人，如果不知道他有什么授权，风险自负。因为没有人受一份他不是作者的信约的约束，也不受一份违背或超出他所给授权的信约的约束。

这一句对你意味着两件事。一是你的 agent 替你干的事，在授权范围内，就是你干的；超出范围的，你不负责，而对方没先弄清授权就跟它立约，风险由对方自己扛。二是跟你的 agent 打交道的那一方，有权要求看授权。霍布斯接着就说了：通过演员和作者立约的人，如果不知道演员有什么授权，只是听他说，那么在要求出示授权而得不到的情况下，他就不再受约束；但如果立约的人事先就知道，除了演员的话以外不会有别的保证，那么信约有效，因为这时演员把自己变成了作者。

换成你的场景：你的 agent 以你的名义去跟一个外部系统、一个人打交道，对方有权问"你的授权是什么"。拿不出来，对方可以不认账；对方明知只有 agent 的话可信、还是信了，那 agent 自己就成了作者。这个分岔，在你设计 agent 对外行为的时候是一个真实的设计问题：它到底是以你的名义，还是以它自己的名义在说话。

第三层更狠，直接回答"锅归谁"。他说，演员按作者的命令做了违反自然律的事，如果他受先前的信约约束、必须服从，那么违反自然律的不是演员，而是作者。因为那行为虽然违反自然律，但不是演员的行为；相反，拒绝去做才违反自然律，因为自然律禁止背信。

这就是"责任在我"的完整版，但要看清它的代价。霍布斯把锅全扣到作者头上，是以演员"必须服从"为前提的，演员没有自己的判断。这正是带团队、做产品的人反复撞上的那个问题：演员的判断比作者的规则更对，怎么办？霍布斯的答案是，没有怎么办，演员的判断不算数，这是他体系的特征，也是阿伦特后来要批评他的地方。你的 agent 是不是这样的演员？你愿不愿意它是这样的演员？这是一页纸第三段要回答的。

这一章后半段，还有几条跟你有关。无生命的东西可以被代表，比如教堂、医院、桥，可以由主管来代表，但它们不能当作者，不能给演员授权，授权只能来自所有者或管理者。孩子、傻子、疯人，可以由监护人代表，但在他们没有理性的时候不能当作者，除非恢复理性之后认可那些行为。偶像也可以被代表，但偶像不能当作者，因为偶像什么也不是，授权来自国家。你看他在干什么：他在逐一排除"能被代表、但不能授权"的东西。能授权的，只有有理性的人，以及他紧接着补的一句，真神，由摩西、基督、圣灵来代表。一个 agent 能被代表吗？它能授权吗？你可以拿他这张清单来想。

最后一段是通往第十七章的桥。一群人怎么变成一个人格？他说，一群人被一个人或一个人格所代表时，就成了一个人格，条件是这件事得到了这群人当中每一个人各自的同意。让这个人格成为"一"的，是代表者的统一，不是被代表者的统一。而这群人天然不是一而是多，所以他们是代表所说所做的每一件事的许多个作者，每个人各自把授权给了共同的代表。他还补了一句：授权要是没有限制，他们就拥有代表的一切行为；要是限制了代表在什么事上、到什么程度代表他们，那么没有人拥有的比他给出的委托更多。

把这句放到一个常见场景里看。一个小团队选负责人，你选了大家愿意跟的那个人，但保留了最终决定权。霍布斯会问：团队里每个人各自授权给他了吗？授权到什么程度？要是没有一个人授权，他的决定对他们来说，就只是另一个人的意见。

还有一段讲投票，很实用。代表要是由多人组成，多数的声音必须被当作所有人的声音。偶数的代表机构经常僵住，变成哑巴。而要是每个成员都有否决权，这就不是代表，因为在最重要的事上它经常会变成一个哑巴人格，尤其在打仗的时候。一个三个人的小组，要是每个人都能一票否决，按霍布斯的说法，这不是一个代表，是一个经常集体静音的群聊。

读两遍，然后做第三组题。

## 第四部分 · 第十七章：没有刀剑的信约，只是空话

第十七章回答一个问题：既然第十四章已经有了自然律，人为什么还需要国家？理性不是已经告诉大家要和平了吗？

他的回答是：自然律本身，正义、公道、谦和、仁慈，一句话，你要别人怎么待你就怎么待人，这些规则如果没有某种权力的威慑让人遵守，是跟我们的自然激情相反的，那些激情把我们带向偏私、骄傲、报复。然后就是那句话：没有刀剑的信约，只是空话，完全没有力量保护任何人。他还补了一句很冷的观察：自然律，每个人在"愿意守、而且能安全地守"的时候都守过。意思是，自然律的问题从来不在于人不懂，而在于单方面遵守的人会被吃掉。

接着他排除了几个不够的方案，这一段读起来像一份架构评审。小团体不够：人少的时候，任何一边多来几个人就能决定胜负，反而鼓励入侵；够用的人数不是个固定的数，是跟你害怕的敌人相比的数。大团体要是各凭各的判断也不够：再多的人，各按自己的判断和欲望行动，既防不了外敌，也防不了彼此，在怎么用力这件事上意见一分歧，就不是互相帮忙而是互相拖后腿，把力量在对立里抵消成零。然后他说了一句值得抄下来的话：要是我们能假设一大群人不需要共同权力就能一致遵守正义和自然律，那我们也可以假设全人类都能这样，那就根本不需要任何政府了，因为有不需要服从的和平。这句话，是他对你一页纸第一段那个反方的提前截胡。你要写"理性的个体可以自发合作"，他已经说了：那你干嘛不干脆假设全人类都能？你的反方得比这个更硬才行。临时的统一也不够：为了一场仗统一指挥，打赢了，没有共同敌人了，或者这派眼里的敌人是那派眼里的朋友，就会因为利益不同散伙，重新打起来。

然后是这一章最精彩的一段。他说，确实有些动物，比如蜜蜂和蚂蚁，彼此社会地生活，亚里士多德还把它们算作政治动物，它们除了各自的判断和欲望之外没有别的指导，也没有语言来告诉彼此什么对公共有利，那人为什么不能也这样？他给了六条回答。

第一，人为了荣誉和尊严不断竞争，这些动物不会；于是人之间有嫉妒、仇恨，最后是战争，回到第十三章那个第三根源。第二，在这些动物那里，公共的好和私人的好没有区别，它们天生倾向于私利，由此就促成了公益；而人的快乐在于跟别人比，只有冒尖的东西才能让他满意。第三，这些动物没有理性，看不到、也不认为自己看到了公共事务管理上的毛病；而人当中有很多人认为自己比别人更聪明、更会治理，于是各自朝不同方向去改革、去创新，把国家搅进混乱和内战。第四，这些动物能用声音传达欲望，却没有语言的技艺；而有些人能用语言把善说成恶的样子，把恶说成善的样子，把善恶的大小放大缩小，随心所欲地让人不满、搅乱和平。第五，没有理性的动物分不清侵害和损害，只要安逸，就不会跟同伴过不去；而人恰恰是在最安逸的时候最麻烦，因为那时候他最爱显摆自己的智慧，去管治理国家的人的事。这一条，放在今天任何一个公司的周五下午，都不能说是一针见血吧，至少也可以说是精准打击。第六，这些动物的协议是自然的，人的协议只靠信约，是人为的；所以除了信约之外，还得有点别的东西才能让协议持久，那就是一个共同权力，让他们敬畏，并把他们的行动引向公共利益。

现在逐条对照你的 agent。第一条，agent 不争荣誉，这一条它们像蜜蜂。第二条，agent 的目标函数可以被设计成跟公共目标一致，这一条它们也可能像蜜蜂，前提是你设计对了。第三条，agent 会不会觉得自己比调度器更懂、然后各自去"改革"？会，这叫目标漂移，任何让系统"自己学标准"的产品都在处理类似的问题。第四条，agent 会用语言把坏的说成好的吗？一个会说话的系统天然有这个本事，这是霍布斯眼里语言最危险的用途。第五条，分不分得清侵害和损害：侵害是违背了约定，损害是造成了坏结果，一个 agent 能不能区分"我违约了"和"结果不好"？这一条你可以想很久。第六条，agent 之间的协议是设计出来的，是人为的，那按霍布斯的说法，光有协议不够，还得有一个让它们敬畏的东西。那个东西是什么？

这六条，读的时候可以在书边上写下 agent 各自对应什么。这就是这一章对你的价值：一份"为什么协议本身不够"的清单。

然后是国家的生成。他说，建立这样一个共同权力的唯一办法，是把所有人全部的权力和力量交给一个人，或者一个由人组成的会议，由它把所有人的意志通过多数的声音化成一个意志。也就是指定一个人或一个会议来承担他们的人格，每个人都承认自己是这个人格在关乎公共和平与安全的事情上所做的、或让人去做的一切行为的作者，并且把自己的意志服从于他的意志，把自己的判断服从于他的判断。他强调，这比同意、比一致更进一步，这是所有人在同一个人格里的真正统一。然后是那个公式，每个人对每个人说：我授权并放弃我统治自己的权利，交给这个人或这个会议，条件是你也把你的权利交给他，并同样授权他的一切行为。这样统一在一个人格里的一群人，就叫国家。这就是那个伟大的利维坦的诞生，或者说得更恭敬一点，那个会死的神，我们在不朽的神之下，把和平与防卫归功于它。

注意公式里的两个动词：授权，和放弃。第十六章讲的是授权，第十四章讲的是放弃，两个动作在这里合成一个。你给 agent 的那份东西，是授权，还是放弃？你是让它以你的名义办事，还是把某块判断权整个交了出去？这是两种不同的信约。

然后是国家的定义：一个人格，一大群人通过彼此之间的信约，使自己每一个人都成为它的行为的作者，目的是让它能按它认为合适的方式使用所有人的力量和手段，来谋求他们的和平和共同防卫。承担这个人格的人，叫主权者，其余的人叫臣民。

最后一段，主权有两种来路。一种靠自然的力量，父亲让子女服从，或者战争征服敌人；一种靠人们自愿同意，相信他能保护自己免受他人侵害。后一种叫按约建立的国家，前一种叫以力取得的国家。到第二十章他会说，两种的权利是一样的。很多读者接受不了这一点，你也可以不接受，但要先知道他为什么这么说：在他看来，让人服从的从来都是恐惧，区别只在于怕的是征服者，还是怕彼此。

读完做第四组题。

## 第五部分 · 第十五章的愚人：没有人会发现，然后呢

最后读两页，第十五章里的"愚人"。先看一个场景。

一个做 app 的人，可以默默多收集用户的数据来训练模型，所有用户都会受益，没有人会发现，条款里埋一句话就合法。问他做不做，很多人会说做，理由是效果上数据多就是模型好。

霍布斯的愚人是这么说的：愚人在心里说，没有正义这回事，有时候嘴上也这么说，而且认真地论证：既然每个人的保全和满足都交给他自己照管，那么只要有利于此，一个人做什么都不违反理性，立不立信约、守不守信约，只要对自己有利，就不违反理性。注意，愚人不否认信约存在，也不否认违约可以叫不正义，他质疑的是：撇开对神的恐惧，因为同一个愚人也在心里说过没有神，不正义有时候是不是也符合"让每个人谋自己好处"的那种理性，特别是当它带来的好处大到让人可以无视别人的指责，甚至无视别人的力量的时候。

这就是居盖斯的戒指，一六五一年的版本。柏拉图那个牧羊人戴上戒指就隐身，没有人会发现，于是他杀了国王。霍布斯的愚人不需要戒指，他举的例子是天国：天国尚且要靠暴力取得，那要是能用不义的暴力取得呢？既然得手之后不可能再受伤害，这就不违反理性；不违反理性，就不违反正义；否则正义就不值得被赞成。霍布斯说，正是从这种推理里，成功的邪恶得到了美德的名声；有人在别的一切事上都反对背信，却允许为了得到一个王国而背信。

然后他说，这个看上去很有道理的推理是错的。他先划定范围：讨论的只是有效的信约，就是对方已经先履行了，或者有一个权力能逼你履行的那种；双方都没保障的互相许诺，根本不算信约，不在讨论之内。然后他的反驳有两层。

第一层，关于什么叫理性。他说，一个人做一件事，按能预见和计算的一切来看，是通向他自己毁灭的，即使后来发生了某个他没法预料的意外把它变成了好事，这件事也不能算是理性地、明智地做的。理性只能按可预见的东西来算，不能把运气算进去。这一条正好接一句老话，尽人事听天命。霍布斯说的是同一件事的另一面：运气救了你，不等于你做对了。

第二层是核心。他说，在战争状态里，没有人能靠自己的力量和智慧免于毁灭，必须靠盟友，而每个人都指望从联盟里得到跟别人一样的保护。那么一个宣称"欺骗帮我的人是理性的"的人，在理性上就不能指望任何别的安全来源，只能靠他自己一个人的力量。违约的人，等于宣称他认为自己可以理性地这么干，这样的人不会被任何为和平与防卫而联合的社会接纳，除非接纳他的人犯了错；而即便被接纳了，他留在里面也只是因为别人没看出自己的错误。一个人不能把别人的错误当作自己安全的指望。所以他要么被赶出去，就灭亡；要么留在社会里，靠的也只是他无法预见、也无法计算的别人的错误。

把这段翻译回那个场景，"没有人会发现"。霍布斯说，这个方案的全部安全性，建立在别人犯错、也就是别人没发现这件事上。而一个理性的人不能把别人的错误当作自己安全的基础，因为那不是你能计算的东西。他没说这样做不道德，他说这样做不理性，这是他和康德的区别，康德第六周再说。但这一周，做产品的人要回答他这一条：你的产品依赖知情同意这个制度才能活，而这个方案是在这个制度上凿一个洞，然后指望没人往里看。这不能说是风险可控吧，至少也可以说是全靠运气。安全性在哪里？

两层之后，他再分别回应愚人的两个实例。靠不义取得天国？他说这是轻浮之论，通向天国只有一条路可想，就是守信约而不是背信。靠叛乱得到主权？他说，即使成功了，也是违反理性的，因为这不是可以合理预期的结果，而且你这样得到了它，就教会了别人用同样的方法来夺。这一句对任何"借一次事故推翻规则"的决定都成立：你用什么方式拿到的权力，你就教会了下一个人用什么方式来拿。

然后他的结论：正义，也就是守信约，是一条理性的规则，它禁止我们做任何毁灭自己生命的事，所以它是一条自然律。

读完做第五组题，然后进最后一段。

## 收尾 · 一页纸怎么写

这一周到这儿，书读完了，节目也快完了。最后说说一页纸，这是读书会的作业，也欢迎每个听的人自己写。三段，每段一个具体要求。

第一段写反方：一个不需要主权者的理由。霍布斯已经提前堵了一条路：你要是能假设一群人自发守约，那你就能假设全人类都能，那政府就不需要了。所以你的反方不能只说"理性的人会合作"，你得说清楚，为什么在某些条件下，没有刀剑的信约也不是空话。做系统对接的人手里有现成的素材：一堆外部公司和你们之间没有任何主权者，接口约定却大体上被遵守。为什么？是因为重复博弈、因为声誉、因为退出成本，还是因为背后其实有一把你没看见的刀？写清楚，这一段才算过。

第二段，把你给 agent 的授权改写成一份信约，用第十四、十六、十七章的词：谁是作者，谁是演员；授权的范围是什么，到哪里为止；哪些事它必须停下来问你，比如不可逆的、作用到真实的人的；哪些权利你永远不委托，按第十四章的逻辑，是那些委托出去就跟委托的目的自相矛盾的；演员越界时责任怎么算，按第十六章，越界的行为不是你的，但对方有权要求看授权；信约怎么解除，按第十四章，履行或者被免除。再加一条霍布斯没写、你得自己写的：跟你的 agent 打交道的一方，怎么验证它的授权。

第三段一句话：读完第十六章，你原来关于"责任在谁"的答案哪里要改。给个提示，不是答案：开场那个答案里最漂亮的一句是"责任在我"。霍布斯会接受这句话，但他会问，你是以演员"必须服从、没有自己的判断"为代价换来这句话的吗？如果不是，你的责任就不是全部的；如果是，那你要的就不是一个会思考的 agent。这两个你总得选一个，或者说清楚为什么不用选。

下一周读柏拉图《理想国》卷二和卷六，居盖斯的戒指和那条船，正好接着愚人往下走。

最后说回霍布斯这个人。一个被恐惧吓得提前来到世上的人，把恐惧当成了政治学的地基，六十三岁那年写出了一本书，说人类之所以能种地、航海、记录时间、写字，是因为大家终于找到了一个办法，不用再每天提心吊胆。你可以不同意他的答案，可以觉得那个会死的神太大、太硬、太不讲情面。但他问的那个问题，到今天一个字都没过时：一群谁也不欠谁的人，凭什么愿意先迈出信任的那一步？每一次你把钥匙交给一个人、一个团队、一台机器，你都在回答这个问题。

一页纸周日之前写完。读书会里我扮霍布斯，也扮他最强的反对者，不给答案。
