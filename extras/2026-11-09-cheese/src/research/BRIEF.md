# 号外 · 奶酪（送给 Daisy 和 Sichao）— 研究员共用简报

## 题目
给一对喜欢各国历史、聊到过奶酪品鉴的朋友夫妇定制的「号外」专题，一页式交互长页（中文为主稿，可能做中英双语）。
天杰的要求：奶酪的沿革、发展、风味特点；互动环节最好是「奶酪制作 / 发酵的过程演示」和「奶酪搭配 / 品鉴光谱」；拓展部分跨全球找其他保存奶制品的方式和风味；再加一个以 Whole Foods、Eataly 这类奶酪货柜为背景的导购。
站点规矩：不写台湾相关信息；不碰时政话题；图片只用真实照片 / 原始文献扫描（不要 AI 图、不要插画）。

## 规则（所有研究员）
1. **先写骨架再核**：开工第一步就把输出 JSON 建好（结构见各自任务），每查完一节就覆盖写回一次，中断也留得下半成品。最后一条回复只报文件路径、条目数和最重要的 5 条「存疑 / 待核」，**不要**把全文贴在回复里。
2. 每条事实写：`zh`（中文一到三句，简洁事实，不写评论腔）、`en`（同义英文）、`year`/`date`（能给就给）、`num`（关键数字，带单位与口径）、`conf`（高 / 中 / 低）、`sources`（[{title, url, kind: 官方|学术|媒体|百科|二手|企业}]，至少一条；官方 / 一手 / 学术优先；百科只作线索）。
3. 两说并存时都写出来（`alt` 字段），不替读者下结论；传说标明是传说。
4. 不要在 zh/en 里写给编辑看的话（「待核」「本路」「建议页面」之类放到 `note`）。
5. 搜索次数有上限（见各自任务），WebFetch 打开已知网址不计。全会话共用搜索额度。
6. 云端 shell 访问外网多数被拦；用 WebSearch / WebFetch。
