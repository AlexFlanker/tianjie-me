# DESIGN.md · 第 9 题「起于微末」· 皮肤「水面」

（2026-11-14；会话自定，天杰可改。字体按站点规矩固定，不引入第三种。）

## 1. 这页要讲清什么
一个很小的起点，一站一站牵动全世界；同一种「小」，有的卡住了世界，有的推了世界一把。页面上所有图形只表示两件事：**从哪里出发、先后牵到哪里**（涟漪与弧线），和**这是哪一类**（卡住 / 推一把）。

## 2. 气质
一张摊开的纸面，像静水；一个点落下去，圈一层层扩出去。克制、平、冷静，不做灾难片也不做励志片。深色是夜里的水面。

## 3. 颜色（全部走 :root 令牌，SVG 取色也走令牌）
| 令牌 | 浅色（默认） | 深色「夜里读」 | 用途 |
|---|---|---|---|
| --bg | #F4F1EA | #0C1318 | 纸 / 水面 |
| --surface / -2 / -3 | #FBF9F4 / #ECE8DE / #E1DCCF | #131C23 / #1A262F / #22313C | 卡片、悬停、舞台底 |
| --ink / --ink-2 / --muted | #1A1F24 / #3C444C / #6E767D | #E9E6DE / #BCC2C4 / #87929A | 墨 |
| --line / --line-2 | 墨 24% / 11% | 纸白 26% / 12% | 细线 |
| --block | #B0361F 朱砂 | #E8725A | **卡住**：只用于这一类的标记、弧线、链条 |
| --boost | #22705D 石绿 | #5CC2A6 | **推一把**：同上 |
| --glass | 纸白 90% | 墨蓝 88% | 导航、舞台卡片（配 12px 模糊；reduced-transparency 时改实色） |

- 两类**同时用形状区分**：卡住 = 菱形（转 45° 的方块），推一把 = 圆。凡是出现类别的地方（图例、地图点、刻度尺、列表行、时间轴端点）颜色与形状一起出现，色觉差异下仍可分辨。
- 朱砂与石绿不作装饰用；按钮的「选中」只用墨色反白。焦点环用石绿。
- 地图底图是 NASA 蓝色弹珠（真实卫星合成图）：浅色下去饱和提亮再罩一层纸色，深色下压暗；`--map-filter`、`--map-veil`、`--map-ink`、`--map-halo` 四个令牌控制。

## 4. 字
- 标题 Noto Serif SC 700（副题 500），正文与界面 Noto Sans SC 400 / 500 / 600 / 700；数字 tabular-nums。
- 字号只用 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36 / 48 / 60 / 96；正文 16/28，说明 14/24，图注与标签 12/20。中文行高放宽（≥1.7）。
- 图上的字恒为 12 px：地图与时间轴都按容器实际像素在 JS 里画，不随 viewBox 缩放。

## 5. 间距、圆角、线
- 间距 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64 / 96；章与章之间 96。页边 `--gut: clamp(16px, 3.2vw, 40px)`，`.wide` 只写 padding-left / right。
- 圆角只有 2（按钮、图片、框）、4（舞台卡片）、999（案例小标签与圆形标记）。
- 无阴影、无装饰性渐变（卷首图上的压暗罩除外）；层次靠 1px 细线与纸色深浅。

## 6. 动效
- 缓动统一 `cubic-bezier(.22,1,.36,1)`：颜色 300 ms，位移 500 ms，入场 700 ms 一次。
- 舞台镜头：viewBox 补间 1.1 s；到位后起点发出三圈涟漪（循环），因果链每 1.5 s 点亮一站（弧线沿大圆画出）。
- 论点逐词点亮跟滚动走；列表换透镜用 FLIP 500 ms。
- `prefers-reduced-motion`：镜头直接切换、因果链一次全亮、涟漪画成两圈静止的圈、入场与逐词点亮关闭。

## 7. 组件与状态
- 按钮 `.btn`（卷首唯一动作）、`.sbtn`（透镜 / 控制）：默认、悬停（边线变墨）、按下（下移 1px）、选中（墨底反白）、禁用（40%）、焦点环。
- 案例小标签 `.chip`：默认、悬停、选中、被筛掉（30%）。
- 列表行：悬停底色、展开箭头旋转、`aria-expanded`。
- 舞台卡片：内容放不下时依次收紧——收起照片 → 只展开当前一步 → 收起「大」一句 → 只留当前一步；任何视口不裁字。
- 图注分两段：说明一段、署名（作者与许可）一段，署名不许被截断。

## 8. 版面
卷首（全幅图 + 题号 + 标题 + 一个动作 + 一行依据）→ 论点（逐词点亮 + 两类图例 + 三个数字）→ 吸顶章节导航（进度线 + 深浅色切换）→ 00 序章全屏舞台（地图铺满；左上题签、左下卡片、底部按对分组的刻度尺；≤760 px 宽改为 地图 / 卡片 / 刻度尺 上下叠放；矮屏横放改左右两栏）→ 这一周 → 01 涟漪图（地图 + 读数面板 + 案例标签）→ 02 要等多久（两种看法的横条图 + 可拖竖线）→ 03 案例透镜列表 → 卷末（全部折叠）。

## 9. 不做
不画具象物（船、火山、人）——具象一律用真实照片；不引入第三种字体；不用第三种强调色；不给章节起花哨编号。
